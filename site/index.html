ESP32-S3 HID Bridge

An ESP32-S3 connected to the streaming PC that provides USB controllers, keyboard, and mouse for Sunshine.

An independent community project. Not affiliated with LizardByte, Espressif, Microsoft, or Sony.

How it works

MoonlightYour controller, keyboard, and mouse input travels to the host.
SunshineHands the input to the bridge over a USB serial link.
ESP32-S3Plugged into the host, it shows up as real USB devices.
WindowsLoads its standard drivers for the devices. Games see an Xbox or PlayStation controller.

The bridge holds two devices at a time. Keyboard and mouse share one, which leaves one gamepad (Xbox, DualSense, DualShock 4, or Switch Pro). Without keyboard and mouse you get two gamepads, of which at most one can be Xbox.

Flash your ESP32-S3

  1. Use Chrome or Edge on a desktop. Firefox and Safari can't talk to USB serial devices.
  2. Plug the board in with a USB data cable on its native USB port (on boards with two ports, the one labelled USB, not UART).
  3. If the board already runs the bridge, or the browser shows no port: hold BOOT, plug it in (or tap RESET), then release BOOT.
  4. Click Install, pick the port, and confirm. It takes about 30 seconds.
  5. Unplug and replug the board. It now appears as ESP32-S3 HID Bridge.
Your browser can't flash devices. Open this page in Chrome or Edge on a desktop. Flashing needs a secure (https) page. Firmware 0.1.0 · 4 MB image, works on 4/8/16 MB boards · status LED on GPIO21 (XIAO ESP32S3)
Not supported: boards with octal flash, such as the ESP32-S3-DevKitC-1 N32R8V (WROOM-2 module), and boards whose only USB port goes through a CH340/CP2102 serial chip. The bridge needs the S3's native USB.

Set up Sunshine

  1. Install a Sunshine build with ESP32-S3 bridge support (see the esp32-bridge branch).
  2. Plug the bridge into the streaming PC before starting Sunshine.
  3. On first start Sunshine selects ESP32-S3 USB Bridge as the gamepad backend by itself. You can also pick it under Configuration → Input → Gamepad Backend.
  4. Leave ESP32-S3 Bridge Port empty to detect the bridge automatically, or enter its COM port.
  5. The first time Sunshine connects, the bridge LED blinks quickly. Press BOOT on the bridge within 30 seconds to pair it with this PC. Until then the bridge ignores input.

Pairing and settings

The bridge only accepts input from programs it is paired with, so other software on the PC can't use it to type or click. It stores up to four pairings. Pairing, removing a pairing, and turning the requirement off all need a press of the bridge's BOOT button. Holding BOOT for 10 seconds removes every pairing.

Quit Sunshine first: only one program can open the bridge's serial port at a time. Chrome or Edge on a desktop is required.

Troubleshooting

SymptomFix
No port appears when flashingHold BOOT while plugging in. Try another cable; many USB-C cables are charge-only.
Flashing works but the board doesn't show up as a bridgeUnplug and replug it. Make sure you're on the native USB port.
Sunshine doesn't use the bridgePlug the bridge in before starting Sunshine, and check that the gamepad backend is set to ESP32-S3 USB Bridge.
Controllers briefly disconnect when someone joinsExpected: every device change makes the bridge reconnect for about a second.
Sunshine log says the bridge is not pairedPress BOOT on the bridge while its LED blinks quickly. If it has four pairings already, remove one under Pairing and settings.
Connecting here fails with "update the firmware"The board runs firmware older than 0.2.0. Flash the current firmware above.
A second gamepad doesn't appearThe bridge is full. Keyboard and mouse use one of its two slots, and only one Xbox controller fits.
