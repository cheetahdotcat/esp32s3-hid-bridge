ESP32-S3 HID Bridge

Firmware that turns an ESP32-S3 into USB gamepads, keyboard, and mouse for Sunshine.

Community project, not affiliated with LizardByte, Espressif, Microsoft, Sony, or Nintendo.

Sunshine sends input to the board over USB serial. The board presents it as standard USB devices. It has two slots: keyboard and mouse share one, and each gamepad takes one. At most one gamepad can be Xbox.

Flash

  1. Use Chrome or Edge on a desktop.
  2. Connect the board's native USB port with a data cable.
  3. If no port shows up, hold BOOT while plugging in.
  4. Click Install and select the port.
  5. Replug the board when done.
This browser can't flash devices. Use Chrome or Edge on a desktop. Flashing requires https. Firmware 0.2.0 · status LED on GPIO21 · other builds

Not supported: octal-flash boards (e.g. DevKitC-1 N32R8V) and boards whose only USB port is a CH340/CP2102 serial chip.

Sunshine

  1. Install a build from the esp32-bridge branch.
  2. Plug in the board, then start Sunshine. It selects ESP32-S3 USB Bridge automatically (Configuration → Input → Gamepad Backend).
  3. On first connection the LED blinks fast. Press BOOT to pair.

Pairing

The board only accepts input from paired programs (up to four). Changes below must be confirmed with BOOT. Holding BOOT for 10 seconds removes all pairings.

Close Sunshine first; the serial port can only be open in one program.
